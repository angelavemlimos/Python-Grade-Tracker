(a) Three biggest differences between Python and another programming language:
1. Python uses clean indentation (4 spaces) instead of curly braces ({}) to define code blocks.
2. Python uses dynamic typing without requiring explicit type declarations (like int or String) for variables.
3. Python statements do not require semicolons at the end of lines.

(b) One bug I hit and how I fixed it:
I initially encountered a TypeError when trying to perform arithmetic directly on the raw input() return value. I fixed this by explicitly wrapping the input call inside float() conversion logic.
